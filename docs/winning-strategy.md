# 勝つための要諦 — 公式IP × ファン創作アプリ

> ポジショニングの軸：**公式IPを使って、ゲームや日常アプリなど多様なアプリを、誰でも作って公開・収益化できる**。
> このとき勝敗を分けるのは「作れること」ではなく、**IPホルダーの信頼と供給**、そして**実際に毎日使われること**。

## 勝ち筋の再定義
公式IPは "供給が王様"。供給側（IPホルダー）は強く・少なく・ブランドに保守的。
→ **"安全に・低労力で・儲かる形で" ファンにIPを開放できる標準** になった会社が勝つ。

## 抑えるべき決定的な4つ（優先順）

1. **IPホルダーの信頼と供給（最重要）**
   - パック単位の承認 + AI自動チェック + 監視 + 即時テイクダウン（毎回承認で消耗させない）
   - セルフサーブのライセンス + 監修AI（属人化した監修をDX＝低労力の鍵）
   - 透明・監査可能なロイヤリティ + ファン嗜好インサイトの還元
   - 使えるアプリ種別 / トーン / 地域 / 期限 / 承認モードの粒度細かい制御
   - marquee IP を1社落とす → 社会的証明の連鎖
   - 失敗モード：承認の摩擦が高い／ブランド毀損1件 → IPホルダーが逃げる

2. **「毎日使われる」需要（北極星）**
   - 定着する実用性 + 週次アクティブ計測 + 配布ループ（共有リンク／PWA／出典バッジ）
   - 失敗モード：クリエイターは集まったがエンドユーザーが毎日使わない → 全崩れ

3. **トラスト＆セーフティを"製品"にする**
   - 自動 + 人手レビュー、悪用検知、迅速なテイクダウン、明確な出所表示
   - 堀であり、同時に存亡リスク（1件の炎上が提携を殺す）

4. **生成物の品質を"制約"で担保**
   - 任意コード生成にしない。自社管理の高品質テンプレ／ランタイムのキュレーション集にIPを載せる
   - テンプレは意図的に拡張。ゲームは水準が高いので日常アプリで定着を証明してから

## 勝つ順序（幅より深さ）
1. PDでループを実証（安全・速い）
2. marquee IP を1社（日本の推し活経済＝VTuber/アイドル/アニメが最有力ビーチヘッド）
3. 証明後に拡張（テンプレ増 → ライトなゲーム → 既存ツールへのIP差し込み → グローバル）

## 現状との差分
- 出来ている：ライセンス権利システム、自動審査の骨格、WAU計測、収益3分割、PD素材＋実アプリ、共有配布
- 足りない（次に抑える）：IPホルダー向け運用信頼層（監修ダッシュボード・パック承認・監視・インサイト還元）、監修AIの実装、需要の永続的実証、品質の制約設計、最初のIP提携の営業ストーリー

## 一言
コード生成は仕入れ（コモディティ）。我々の付加価値は、それを **権利・信頼・分配・配布・"使われること"** の文脈に統合して秩序を発生させること。堀はそこにしかない。
